# Get-ForegroundWindow

## SYNOPSIS

PSCX Cmdlet: Returns the hWnd or handle of the window in the foreground on the current desktop. See also Set-ForegroundWindow.

## SYNTAX

### __AllParameterSets

```
Get-ForegroundWindow [<CommonParameters>]
```

## ALIASES

None

## DESCRIPTION

Returns the hWnd or handle of the window in the foreground on the current desktop.
See also Set-ForegroundWindow.
